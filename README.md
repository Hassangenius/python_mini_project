# python_mini_project

Plants care tracker: is a dedicated python-based program to document the journey of plant care

using many technologies and libararies, platforms.

program phases: 

1- Add plant name & details
2- Record plant care activity: it helps the user to record his plant activity attached with date and time such as: fertilizing, watering, repotting, prunning
3-record plant growth: user can measure the growth of his plant by adding the height of his plant
4-plants due for care: sends a reminder to the user with specified activity and timing by user
5-Search for plant name or location
6-View all plants
7-View growth History: the height of plants
8-Diagnose a plant: based on synptoms
9-Plant type tips


Libraries used 
A-Pandas: platform that enable analyze and store data
B-Streamlit: a platform used to add inputs that makes the program interactive
C-Os: data files management
D-openai


Programming environment: Jupyter python for programming

storing data: in excel file as CSV
